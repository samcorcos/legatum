# Aztec music from OpenGameArt (2026-11-26)

- **The music existed; the search had the wrong shelf.** Packaged open-source games have no Mesoamerican soundtrack, but OpenGameArt has four pieces by Alexandr Zhelanov written for a game about the Aztecs (CC BY 3.0 and 4.0). A web search by subject and licence found them in one query.
- **A device folder link shares the cloud's network.** The Linux shell that a connected folder gives runs behind the same allowlist, so it cannot reach a host the cloud cannot. A download from such a host has to run on the machine itself, and the files then come across by staging them from the folder.
- **Guide credits match authors by pattern.** The FreeCol credit matched `/Zhelanov/` with CC BY 4.0, which would have claimed *Ritual Traps* (same composer, same licence, different source). It now matches the FreeCol pair's second author.
- **Playlist order is manifest order.** A people's first track in the manifest opens its playlist and stays all game, so `build_aztec.py` inserts its tracks ahead of the Aztecs' older ones.
