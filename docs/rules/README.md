# Game rules

The code-verified rules reference (orders, turn resolution, what is available when, costs, factions, and the systems
that do not exist) is [`.claude/skills/legatum-rules/references/index.md`](../../.claude/skills/legatum-rules/references/index.md) (one file per system).
It lives beside the skill that loads it for AI agents, and any change to a rule or mechanic updates it in the same
change. [`.claude/skills/legatum-rules/SKILL.md`](../../.claude/skills/legatum-rules/SKILL.md) explains how to use it
before proposing a mechanic.
