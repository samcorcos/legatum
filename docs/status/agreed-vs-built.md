# Agreed vs built

A standing ledger of what the designer decided or approved, set against what is on `master`. First cut 2026-10-31 (master `03f4e2369`), written by the delivery audit. The ops supervisor updates it every run; a decision is not finished until its row says `done`.

**Sources swept (2026-10-10 onward):** the design doc decisions log (110 rows, 10-10 to 10-31); decisions marked "user" in the `legatum-design`, `legatum-factions`, `legatum-ui`, `legatum-art` and `legatum-workflow` skills; `docs/archive/review-plan-2026-10-18.md` (approved in full); `docs/status/next-tasks.md` and `tracker.md` including the "Decisions-log rows owed" lines; `.progress/astra-queue/hold/` and `running/`; every unmerged `astra/*` and `claude/*` branch.

**Status words:** `done` (on master, seen in code or the rules reference) / `built-not-merged` (a branch holds finished work; head named) / `running` (an agent or task is on it now) / `not started` (counts as dropped unless a deferral is cited) / `parked` (reason and source cited) / `superseded` (by which decision) / `abandoned` / `process` (a working rule, not a deliverable).

**How strict:** `parked` and `superseded` need a cited source. Without one the item counts as dropped. Code beat docs wherever they disagreed. The six sweeps were done by sub-agents; I spot-checked Sparta's siege exemption, the Germany and Mongol decision, aircraft art, India and mounted branch state against master. Evidence is a file, a commit or a review report.

**Staleness note (2026-11-07 doc audit):** this ledger is the 2026-10-31 snapshot with later rows added by hand. Rows that no longer describe master are marked SUPERSEDED or DONE inline; the rest were not re-checked. Faction decisions since 10-31 live in the `legatum-factions` skill (Germany rework 11-05/06: Forge-slot Ruhr Foundry +6, double strategic supply, −2 Food, no movement penalty; Aztecs shipped 10-31; the 11-06 rule cuts: Sparta slow heal, Mongol Peace passage, Celtic Ambusher, Swiss wonder buying, Byzantine Scriptorium; Walls at 100; Athens' Greece Captive; two-party Peace; and the decided but unmerged Byzantium Theodosian Walls kit and Germany discount cut).

**Freeze note (2026-11-11):** the designer lifted the 11-07 freeze ("lift the freeze and add the things that are backlogged"); rows below that say the freeze blocks them are unblocked. Earlier note: no rule freeze (designer, 2026-10-31, reversing the 10-30 freeze): rule changes land as issues are found.
