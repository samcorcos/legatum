# UI clarity audit, 2026-09-28 (G13)

Tested in the real app (WASM core) at 1440×900, 1024×768 and 390×844, in Atlas and Court, on a new game and a turn-46 save.

The test for every screen is pillar 9: within 5 seconds, is it clear what decision is wanted, with one primary action, a visible trade-off, nothing to scroll past, and no numbers without meaning?

Status: **Fixed** (first pass: `worktree-agent-a3ff080be7ffa5851`; **Fixed (pass 2)**: `worktree-agent-a89f3908540f3c73b`, 2026-09-29), **Open** (not done), **Routed** (another agent owns the file).
