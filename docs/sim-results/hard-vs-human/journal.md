Each experiment gets one dated entry: what we tried, the result with numbers, what we learned, and what's next. Newest at the bottom. The rundown is written from this file.

## 2026-10-08 — Distilled macro value (`astra/distilled-macro-value`): opening pilot useful, plan replacement rejected
- **What we tried:** 64 shared, view-derived rollout samples per candidate at H40 or H80 on benchmark-map and seeded Standard four- and eight-player positions, all factions. Two 128-game collections yielded 1,500 and 1,857 decision groups. The second preserved campaign memory at sampled reviews. A ridge fit of pairwise win-chance differences became ten fixed-point integer plan/opening heads over view-only features. The `learned_macro` gene is off by default; opening-only mode is restricted to four or more players. Native release inference was 261 ns per option at a T60 eight-player view.
- **Held-out:** on the first 371 groups, openings agreed with the 64-sample oracle 51.8% versus 43.5% for the first two samples; macro-only plans agreed 60.1% versus 73.9%. The warmed second fit did not rescue plans (59.9% versus 72.8% for two samples on 302 macro reviews). The first fit did better than the second on the second pass's 168 held-out openings, so it remains the installed but disabled weight set.
- **Full games:** 64 salts on each of the five human maps: Hard + Search control 43.13% overall, opening-only 46.88%, with Sparta 1/64 → 13/64 wins and the other four maps' win outcomes unchanged. Paired overall gain +3.75 points (salt bootstrap 95% CI +1.88 to +5.94). Sparta's median winning turn was still T253 versus the human's T61. Plan-only fell to 40.31% overall; both mode reached 47.19% but lost 12 Mongols wins. In the 1,024-game Standard Small duel versus proxy7, the guarded opening-only mode matched control's 35.40% with zero changed outcomes. The gene stays off until a broader four/eight-player validation supports promotion.
- **Limit:** training and benchmark evaluation share map layouts, although seeds are split. The first and second held-out sets were used for model comparison; the final benchmark uses the same salts as pilot selection. The historic 8.5 T14 tape has 14 hash mismatches on this branch, so its model score is only approximate. The rollout policy's win-chance estimate is not an observed final game result, and tactical execution still limits Sparta.
- **Cost and next:** 16 task AWS batches, including pilots and both data collections, about 1.408 server-hours and $1.00 at launch spot price; invoice unverified. See `docs/sim-results/distilled-macro/` for raw labels, fit reports, full-game runs and cost ledger. Next, improve the plan labels/features before enabling plan replacement, then validate a fresh four/eight-player map set and new human games.

## 2026-10-08 evening — Relative value and projected title transfers (Codex)

- **Audit:** `WinFacts` already uses each team's public VP, cities, population and Largest Economy in a softmax race, so a rival's loss raises our chance and the same loss to a likely winner matters more.
