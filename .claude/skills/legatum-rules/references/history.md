a missing or different version is refused. The app reports the saved Playtest label when available and asks the player to start a new game (`app/src/saveErrors.ts`, `app/src/screens/TitleScreen.tsx`). Saving and loading a current game preserves the state; neither path edits an existing save file. A save with the right version but broken contents is refused by `core/src/validation.rs::check_state` (reached from `wasm::json::parse_state`), whose messages begin "The save is damaged: "; `app/src/saveErrors.ts::loadErrorMessage` shows the player one fixed sentence (file kept, choose another or start a new game) and logs the detail to the console, and `parseSaveFile` does the same for a chosen file that is not a Legatum save or has an unsupported envelope version. Any rule or save-shape change increments the one core constant; there are no save migrations.

**Pre-rules-25 scenario positions (2026-11-08).** Rules 25 moved four resource reveals one tech later, so a position cut before it could show an empire with a resource it could no longer see. `crates/sim/src/scenario_reveal.rs::migrate` grants the new reveal tech (Gunpowder, Industrialization, Combustion, Autonomous Systems) to any empire that already had the old one (Education, Metallurgy, Industrialization, Electricity), and `scenario_cut.rs::run` applies the same repair to saves and extracted states recorded before version 25 (state loads through `parse_state_for_rehash`). The one-off `legatum-sim scenario-reveal-migrate` repaired the 14 Lab cards and 12 war cases; their baselines were re-recorded on Hard.

**Capital VP compatibility (2026-11-01; rules 50 removed `Player::capitals_taken`, an older save's field is ignored).** `PlayerPublic::capitals_taken`, `CityView::original_capital` and `original_capital_of` default when absent, so a save/tape from the current rules version loads without inventing past capital captures. This additive change was made without a rules-version bump at the designer's explicit request for old saves to load; the Future-era tech tree then raised `RULES_VERSION` to 9, so a version-8 save no longer loads at all. The walled-garrison line-of-sight change (train-1102) raised it to 10, and rebase at any distance (2026-11-02) raised it to 11.
