# Third-party notices

Legatum's own code is MIT (`LICENSE`) and its art is CC BY 4.0 (`LICENSE-ART`), except the 3D map's unit models (CC BY-SA 3.0) and its CC0 trees and textures (see Art below). It builds on the open-source
components below, each under its own licence. Last audited 2026-11-22 with `cargo metadata` on the Cargo workspace
and the licence fields of `app/package-lock.json`. No dependency is GPL, LGPL-only or AGPL,
none is unlicensed, and none comes from git or from a path outside this repository.

Where a component offers a choice of licences, Legatum uses it under MIT or, where MIT is not offered, Apache-2.0.

The distributed build (the web build) carries the full licence texts in `THIRD_PARTY_LICENSES.txt`, written by
`tools/release/third-party-licenses.mjs` from the locked dependencies and shown in the game under How to Play, Credits.

## Rust crates

Two lock files: the engine workspace (`Cargo.lock`, 96 third-party crates: core, AI, simulation runner, WASM
bindings) and a development-only probe (`tools/analysis/Cargo.lock`, a subset of the engine's dependencies, never
distributed). The game ships as a static web app, so only the crates compiled into the WebAssembly engine reach
players. Regenerate the per-crate list with `cargo deny list` or `cargo metadata --format-version 1` in the root.

| Licence | Crates | What it asks of a binary distribution |
| --- | --- | --- |
| `MIT OR Apache-2.0` (67), MIT (7), `MIT/Apache-2.0` (5), `Apache-2.0 OR MIT` (3), and other expressions that offer MIT or Apache-2.0 | most crates, including `serde`, `rayon`, `wasm-bindgen`, `flate2`, `mimalloc` (which builds the MIT-licensed mimalloc C library) | Keep the copyright and permission notice. |
| BSD-3-Clause, alone or with BSD-2-Clause | `zstd`, `zstd-safe` and `zstd-sys` (which build the zstd C library; zstd is BSD-3-Clause or GPL-2.0, used here under BSD-3-Clause) | Keep the copyright notice, conditions and disclaimer. |
| `Unlicense OR MIT` | `memchr` | Used under MIT. |
| `(MIT OR Apache-2.0) AND Unicode-3.0` | `unicode-ident` | Keep the Unicode copyright and permission notice. |
| Zlib | `zlib-rs` (not linked on the targets we build) | None for binaries; do not misrepresent the origin. |
| `Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT` | `linux-raw-sys`, `rustix`, `wasip2`, `wit-bindgen` (native targets only) | Used under MIT or Apache-2.0. |
| `MIT OR Apache-2.0 OR LGPL-2.1-or-later` | `r-efi` (UEFI targets only, never built here) | Used under MIT or Apache-2.0; the LGPL option does not apply. |

The Rust standard library, linked into every binary, is `MIT OR Apache-2.0`.

Some crate tarballs (for example `r-efi`) carry no licence file of their own, only the SPDX expression in `Cargo.toml`.
For those, use the standard text of the named licence and the authors in the crate's manifest or repository.

distributed builds").

binaries, pulled in by Vite, unmodified and build-time only.

## Python and other tooling

Scripts under `tools/` and `scripts/` are development tooling and are not part of the game. Some import NumPy
(BSD-3-Clause), PyTorch (BSD-3-Clause), Pillow (MIT-CMU) and boto3 (Apache-2.0), which you install yourself; none is
vendored here. The build also calls `wasm-pack` and `wasm-opt` (Binaryen), and the audio and film scripts call
`ffmpeg`; none of them is redistributed.

No third-party source code is vendored or copied into this repository. `CODE_OF_CONDUCT.md` is adapted from the
Contributor Covenant 2.1 (CC BY 4.0), as it says.

## Notices in distributed builds

MIT, Apache-2.0, BSD, ISC, Unicode-3.0 and the OFL all require their notices to accompany a binary. The distributed
build of Legatum (the web build) must therefore include this file
and the full licence texts of the linked crates and bundled packages, for example a `THIRD_PARTY_LICENSES` file
generated with `cargo about` and `license-checker --production` and linked from the in-game Credits (`tools/release/third-party-licenses.mjs` writes it).
